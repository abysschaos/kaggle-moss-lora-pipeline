# 小白傻瓜式使用指南：从零炼出你的第一个 MOSS-Image LoRA

这份手册专门为**第一次接触 AI 炼丹、看着满屏英文缩写发懵**的用户准备。你不需要懂深度学习公式，只要按照下面三步点鼠标，再在遇到问题时对照"大白话字典"和"翻车速查表"，就能稳稳炼出能直接在 ComfyUI 里出图的好 LoRA。

---

## 一、30 秒极速上手三步走

当你双击根目录的 `MOSS_LoRA_Trainer.exe` 打开控制台窗口后，左侧采用清爽的 **5 大功能选项卡**，右侧则是永久常驻的实时曲线与控制台看板。日常炼丹只需按顺序点这三步：

1. **第一步：在【🚀 快速训练】选一套预设并命名**
   - 选项卡顶部有两排共 8 个预设按钮。你想炼画风就点 `🎨 艺术画风`，想炼人物就点 `👤 单人角色`，只有 10~20 张图怕过拟合就点第二排的 `🛡️ 小图集防过拟合角色`。
   - 点完预设后，把下面的 **LoRA 名称**（英文，如 `my_girl_v1`）和 **触发词** 改成你自己好记的名字。
   - **不知道参数啥意思？** 直接切到第 5 个选项卡 **【📖 指南与工具】**，就能在窗口里直接弹出阅读这本说明书和排障表。
2. **第二步：在【📂 数据与续炼】选好文件夹并点【🩺 一键体检图集】**
   - 在上方快速状态条点 `📂 数据/续炼 ↗`（或直接点击顶部标签【📂 数据与续炼】），选好放着图片和同名 `.txt` 文本的文件夹。
   - **强烈建议点一下【🩺 一键体检图集】**。它会在 1 秒内扫描缺失 `.txt`、太糊的图片、超长被截断的句子以及误填逗号标签，并直接用大白话提示怎么改。
   - 切回 **【🚀 快速训练】**，点一下 `📐 一键对齐推荐步数`（让步数自动匹配你的图集数量；若是首次使用尚未准备底模或引擎，可先点一次【📦 底模与框架】确认自动扫描全部就绪）。
3. **第三步：点右下角绿色大按钮【🚀 启动本地极速训练】**
   - 等几分钟让它先提取文字和图片特征，随后右侧上半区就会开始画实时的 **Loss（损失率）曲线**。
   - 练到一半想先看看效果或者有事要用电脑，随时点旁边的橙色按钮【⏸️ 保存当前进度并暂停】，它会把当时最新那一步的权重安全存盘并导出给你；下次把训练模式切回【断点续炼】就能接着跑。

> **关于电脑里三个大模型文件从哪来**：如果你本机装过 ComfyUI 且里面已经放好了 `moss_image_heal_*.safetensors`（或 base/sft）、`qwen3.5_9b_*.safetensors` 和 `flux2-vae*.safetensors`，启动时软件会自动全盘扫到并填好，不用重下；如果还没下载，请先按 [本地安装部署手册](local_installation_guide.md) 下载到 `models/` 对应子目录。

## 二、8 套一键预设挑选速查表

不知道该怎么组合 Rank、学习率、Mu 和 DoRA？直接按场景点顶部预设：

| 预设按钮 | 最适合炼什么 | 默认悄悄帮你开启了什么黑科技 |
| :--- | :--- | :--- |
| `🎨 艺术画风` | 30~80 张各类画面的统一画风/笔触/色彩 | 关闭 DoRA、梯度累积=1、Mu=-1.09，6G/8G/16G 都能跑得飞快 |
| `👤 单人角色` | 20~50 张固定主角，要脸稳还能自由换装 | 开启 DoRA、LoRA+=2.0、GradAcc=2、Mu=0.35，死锁五官同时不锁死衣服 |
| `👥 多人物配比` | 一个 LoRA 里同时学 2~5 个不同角色 | 开启多子集面板、Rank=48、`+text-refiner` 防多个角色串脸 |
| `🎭 多画风配比` | 一个 LoRA 里通过不同触发词切换多种画风 | 开启多子集面板、Rank=48、`+modulation` 强化全局色彩与线条隔离 |
| `💡 概念/动作` | 特定姿势、光影构图、服装材质或道具 | 对称采样 `Mu=0.0` + `+text-refiner`，把语义精准绑在触发词上 |
| `💎 LoKr 高还原画风` | 追求极致细节还原，同时希望产出文件极小 | 切换到 **LoKr (Factor=8)** + `modulation` + `EMA=0.99`，高频纹理很犀利 |
| `🛡️ 小图集防过拟合角色` | 人物只有 **10~20 张图**，容易一训练就把背景和衣服死记住 | 较低学习率 `6e-5` + **Rank/Module Dropout** 随机丢参数 + `TextDrop=0.1` + `EMA=0.99` |
| `⚡ Muon 画风加速` | 显存足够（且模型按流式运行），希望画风早期成型更快 | 开启 **Muon 正交优化器** 取代 AdamW，自动切换安全 GPU 流式显存档位 |

## 三、5 大选项卡界面与按钮大白话解释

> **窗口分区说明（v1.5.4）**：左侧上方从左到右分为 5 个选项卡（支持 `Ctrl+1`~`Ctrl+5` 快捷键秒切）——① **`🚀 快速训练`**（日常改名、选预设与调参主战场，带胶囊切换按钮与悬浮中文说明、支持一键`📋 预览命令`）、② **`📂 数据与续炼`**（选图集、多子集配比、体检与分段按钮切换 Resume 续炼）、③ **`📦 底模与框架`**（底模路径与引擎下载修复）、④ **`☁️ 云端遥控`**（v1.6.0 规划与现有 Kaggle 文件快捷入口）、⑤ **`📖 指南与工具`**（点按钮直接弹窗看本说明书和运行环境一键自检）；右侧永久常驻 Loss 折线图、终端日志与开始/暂停/终止按钮。

### 3.1 【📂 数据与续炼】命名、续炼与数据集区

| 界面控件名称 | 白话解释：它是干嘛的？ | 新手该怎么填 / 怎么点？ |
| :--- | :--- | :--- |
| **LoRA 与文件夹名称** | 练好以后权重文件叫啥名，存在 `output/<这个名>/` 下 | 只能用英文、数字和下划线（别用中文和空格），例如 `huahuo_v1`。 |
| **自定义触发词 (Trigger)** | 画画时用来唤醒这个 LoRA 的咒语 | 如果你自己的 `.txt` 里**没写触发词**，填在这里，软件会自动给你加到每张图句首；如果 `.txt` 里已经写过了，它会自动识别不重复加。 |
| **训练 / 续炼模式** | 决定从头练、接着练还是拿老模型加练 | **全新训练**：从第 0 步开始；<br>**断点续炼**：之前点过【暂停】后继续跑完，若步数填得比已跑完的还小，会自动变成"再多跑 N 步"；<br>**基于已有 LoRA 继续**：挑一个练完的 `.safetensors`，保留原有画风/人物底子拿新图集二阶段强化。 |
| **自动存盘间隔 (步/次)** | 每跑多少步自动留一份可测试的半成品权重 | 默认 `100`。如果总步数只有 300 步，建议改 `50`，方便后面挑出没过拟合的最好那一版。 |
| **🩺 一键体检图集** | 开跑前的"安检仪" | 每次换新图集必点！它会排查缺 `.txt`、面积过小/过窄图（`< 768²` 或短边 `< 512`）、比例超过 3:1、句子太长被截断，以及误填标签词。 |
| **多子集配比切换按钮** | 同时练多个人/多种衣服/多种画风时用的分装表格 | 点击切到`已启用`即可分别添加多个文件夹并绑定各自触发词。图少的文件夹会吃亏，添加到 2 个以上后点 **【⚖️ 一键配平 Repeat】** 就能按数量反比一键补齐曝光比例。 |
| **结果存放根目录 / ComfyUI 目录** | 练好后模型往哪存，要不要顺手抄一份去生图软件里 | 开启胶囊同步开关后，每 10 秒只要有新存盘就会同步放进 ComfyUI `models/loras/<LoRA名>/`，一边练就能一边去生图测试！ |

### 3.2 核心训练超参数区

| 参数名称 | 白话解释：它在管什么？ | 怎么设才不踩坑？ |
| :--- | :--- | :--- |
| **单图重复 (Repeats)** & **训练轮数 (Epochs)** | 相当于"一轮里每张图看几遍" × "一共看几轮" | 只靠这两个数乘出来总数给【按公式对齐】算步数。画风常用 `3×5` 或 `4×5`，人物常用 `6×4`。 |
| **核心步数 (Steps)** | 优化器真刀真枪更新参数的次数（**真正决定练多久**） | 改完图数、分辨率或 GradAcc 后点一下 **📐 一键对齐推荐步数**。普通单卡画风 400~800 步，人物 250~500 步。 |
| **LoRA 矩阵秩 (Rank)** | LoRA 脑容量有多大（决定能装下多少复杂笔画或特征） | 单画风、单人物选 `32` 最均衡；角色怕过拟合锁死姿势降到 `16`；多人物、复杂光影合集用 `48` 或 `64`。 |
| **缩放系数 (Alpha)** | 训练时权重发挥出来的强度倍比 | `Alpha / Rank` 就是基准倍率。画风设等于 Rank（如 `32 / 32`）；人物如果总锁衣服或泛化差，可尝试设一半（`Alpha=16, Rank=32`）。 |
| **适配器算法 (Algo)** | 用哪种数学结构记录改动（`lora` / `loha` / `lokr`） | 日常选 **`lora`** 最省心兼容性最好；大风格迁移/高密度混合试试 **`loha`**；想要极致细节压缩+小文件选 **`lokr`**。 |
| **启用 DoRA (权重分解)** | 把"特征方向"和"特征强弱"拆开学的加强版技术 | 练人物五官、精修服饰或复杂画风细节时强烈推荐勾选；简单泛画风关掉能稍微快一点。 |
| **LoRA+ 倍率** | 让矩阵里负责输出的 B 分支跑快 2 倍 | 人物和复杂概念建议选 `2.0` 加速轮廓成形；单画风维持 `1.0` 就很稳。 |
| **目标注入层 (Preset)** | 决定改动大模型里的哪些零件 | • 通用首选 **`attn-mlp`**；<br>• 练多种画风/色调选 **`attn-mlp+modulation`**；<br>• 练多个人物/绑定难懂文字概念选 **`attn-mlp+text-refiner`**；<br>• 只有极端风格魔改才动 `full-block` / `all`。 |
| **基础学习率 (LR)** | 每一步修改参数步子迈多大 | 画风常用 **`1e-4`**；人物微调求稳常用 **`8e-5`**（小图集建议 `6e-5`）。太高图会焦黑，太低练完没效果。 |
| **计算精度 / 显存档位** | 防止爆显存、匹配你显卡型号的档位开关 | 显存档位选 `auto` 让程序看你显卡自动配就行（6G/8G 走最省显存通道，12G 走中等，16G 以上高并发）。RTX 30/40/50 系用 `bf16`，老 20 系/T4 自动转 `fp16`。 |
| **训练分辨率** | 把图片按面积缩放到多大再去练 | 标准清晰选 `1024`；如果你是 **16GB 显卡**想提速一倍、或者只有 **8GB 显卡但描述文本特别长**怕被截断，果断切换 **`896`** 黄金甜点分辨率！ |
| **梯度累积 (GradAcc)** | 攒够 2 批图算个平均方向再更新，显存一分不加 | 画风保持 **`1`** 最快；人物五官怕歪、多子集图杂怕互相打架就调 **`2`**。调大后记得到上面点下公式对齐或补步数。 |
| **时间步重心 (Mu)** | 决定训练时把火力集中在"涂鸦早期的构图颜色"，还是"画到最后时的精致五官睫毛" | **官方 `moss` 模式下**：<br>• `-1.09`（默认）火力集中在早期粗噪，最拿手学全球画风与构图；<br>• `-0.60` 多画风；<br>• `0.0` 动作概念全均衡；<br>• **`0.35` 把高比例采样拉去后期精修区，专练角色五官与衣服细节！** |
| **底模计算精度 / Triton 调优** | 底层算力加速开关 | 全部维持默认 **`auto`** 和 **`off`** 即可。用 40 系+ 显卡且原图用的是全精度未量化底模时，可尝试 `fp8_compute`；长期复跑大任务可开 `table` 加速后续。 |
| **文本提取设备** | 用 CPU 还是显卡跑前置的 9B Qwen 文本编码器 | **8G/12G 显卡请务必保持 `cpu`**，用完即释放不占显存。 |

## 四、隐藏折叠抽屉：【▸ 展开高阶算法 / 防过拟合 / 优化器调优区】

绝大多数新手直接用【🚀 快速训练】主面板就足够了。这个紫色展开条默认收起，只有当你遇到"**图集很小总是过拟合**"、"**想精调 LoKr 压缩率**"或"**想尝鲜 Muon 加速**"时才需要点开它：

| 抽屉里的控件 | 白话作用说明 | 使用建议与必避坑点 |
| :--- | :--- | :--- |
| **LoKr 矩阵因子 / Full Matrix / Decompose Both** | **只有当你把 `Algo` 选为 `lokr` 时才会自动露出来**。<br>• `Factor`：压缩力度（`4` 容量大、细节狠；`8` 默认均衡；`16` 极限小文件；`-1` 自动）。<br>• `Full Matrix`：让大矩阵不作低秩压缩，还原度飙升但体积明显变大。<br>• `Decompose Both`：双矩阵对称分解。 | 新手用 LoKr 直接选顶部的 `💎 LoKr 高还原画风` 预设就配好了，别随便同时乱勾选。 |
| **训练归一化层 (Train Norms)** | 允许模型顺便微调网络骨架里的归一化缩放系数（AdaLN / RMSNorm 等） | 重度画风或全身配色剧变时尝试勾选，常规单人人物一般不勾选，防止破坏原生构图稳态。 |
| **RankDrop / ModDrop / InDrop（三层防过拟合 Dropout）** | 炼丹时的"故意随机丢课"抗过拟合药：<br>• `RankDrop`：每步随机遮住 5%~15% 的矩阵通道，逼模型别死背背景；<br>• `ModDrop`：随机让一少部分插件层轮休；<br>• `InDrop`：输入先丢一部分特征。 | 小于 20 张图的角色经常死锁原背景或原衣服？把 `RankDrop` 设 `0.1`，`ModDrop` 设 `0.05` 立刻见效！<br>**铁律防呆**：如果你上方开了 **DoRA**，底层引擎不允许输入丢弃，界面会自动把 `InDrop` 灰掉锁定为 `0.0` 并只在后端保留 RankDrop/ModDrop 生效。 |
| **优化器 (Optimizer)** | 参数怎么往下走找最优解的算法：<br>• `adamw`：经典最稳，兼容 6G/8G 省显存卸载；<br>• `adamw8bit_kernel`：把优化器状态压到极小；<br>• `muon`：利用矩阵正交更新大幅加快画风与二维线性层收敛。 | **重点注意**：因为 `KohakuMossTrainer` 规定非 AdamW 优化器状态必须驻留在 GPU 上且不能启用融合步进，当你选 `muon` 或 `adamw8bit_kernel` 时，后端会**自动帮你切换为安全的 GPU 流式显存档位（如 `ckpt-ring2-actoff`）**，不再走 CPU 卸载，显存偏小的显卡（6G）慎用非 AdamW。 |
| **LR 调度 & Warmup** | 学习率从头到尾怎么变：`cosine` 先大后小慢慢收尾（推荐）；`constant` 全程保持不变；`Warmup` 是开头几步慢慢热身防止刚开始把模型震坏。 | `Warmup` 填 `-1` 会自动取总步数的 5%（同时程序自带安全夹紧，哪怕你总步数才 10 步也不会出现热身比总步数长的报错）。如果配合下面的 `EMA` 做长时间平滑微调，可以试 `constant`。 |
| **WeightDecay & WD 规则** | 防止权重数值越练越夸张的橡皮筋拉力。默认 `0.01` + `moss` 官方规则。 | 一般不动；除非需要极其夸张的特征强化再试改小到 `0.001`。 |
| **EMA 衰减 (0.99 / 0.995)** | 给历史权重记一套"移动平均稳重版"，滤掉最后几百步抽样抖动造成的噪点毛刺。 | 跑 `600` 步以上长程训练或学习率较高出现 Loss 毛刺时，填 **`0.99` 或 `0.995`**，最终导出的就是更柔和干净的 EMA 平均权重；短训 `<300` 步保持 `0.0`（关闭），否则还没跟上就被拖慢了。 |
| **采样分布 (Timestep)** | `moss`（官方专属）、`uniform`（全时间均等）与 `logit_normal`（标准对数正态）。 | 绝大多数场景坚守默认 **`moss`**（注意千万别在训练时把 `shift` 改成 5.0，软件已在底层为你死锁训练 `shift=1.0`）。<br>**巨大警示**：如果切成 `logit_normal`，它的 `Mu` 正负号和 `moss` **刚好反过来**！在 `logit_normal` 里**负数**（如 `-0.5`）才偏向低噪细节，界面会用黄色字直接提醒你；切回 `uniform` 时不需要 `Mu`，输入框会自动变灰。 |
| **TextDrop (空提示词概率)** | 训练时有 5%（默认 `0.05`）的概率故意把文字清空当无条件生成练 | 想增强无触发词纯文本兼容或小图集降过拟合可提高到 `0.1`，维持模型原生 CFG 引导平衡。 |
| **镜像翻转 Flip** | 训练时随机把图片和画面内容左右颠倒做数据扩充 | **人物有不对称领结/肩章、发卡在一侧、或者画面里有文字的严禁勾选！** 只在绝对对称或风景画风不够用时偶尔开启。 |
| **Seed & 导出格式** | 固定随机种子复现同一炉结果；选择导出 `both`（全都要）、`comfy`（只导出即插版）或 `lycoris`（对应底层 `hf` 导出规格）。 | 默认 `0` 与 `both` 最省心，两份都保留着不会吃亏。 |

## 五、训练中看懂监控看板 + 常见翻车急救表

右侧上半部分的 **实时 Loss 折线图**怎么看？
- **蓝色细折线**：每一步的瞬时 Loss；因为每一步随机挑的图片与噪点深度不同，上下剧烈跳动是**正常现象**，不要被某一两步跳高吓到。
- **绿色粗曲线（EMA 平滑趋势）**：真正看收敛就盯这条绿线！只要绿线总体缓慢向下走，说明模型正在稳步学会；MOSS-Image 的正常区间通常慢慢收敛并波动在较低值附近，不用奢望掉到接近 `0`。

遇到翻车时对照下表直接改：

| 我遇到的翻车现象 | 最可能原因与一行对症改法 |
| :--- | :--- |
| **点【体检图集】提示"疑似纯逗号堆砌"** | 你用的是给 SD1.5/Pony 准备的 `1girl, blue hair, ...` 标签格式。MOSS-Image 使用 Qwen3.5 大语言模型编码，请改成完整的英文描述句子（如 `A young woman with silver hair is standing in...`）。 |
| **人炼出来脸很像，但衣服/姿势死锁换不掉** | 典型的过拟合，或者忘记描述服装导致模型把原图衣服绑死进了触发词：<br>1. 确保 `.txt` 把衣服、姿势、背景全部写出来，只删掉天生发色瞳色；<br>2. 点顶部预设 `🛡️ 小图集防过拟合角色`（开了 `RankDrop=0.1` + `ModDrop=0.05`），或把 `Alpha` 调成 `Rank` 的一半。 |
| **强度拉到 1.0 了画画还是毫无变化** | 图没看够或者网络容量不够：<br>1. 把 `Steps` 拉高一些或检查是不是忘记在生图提示词里写触发词；<br>2. 把 `Timestep Mu` 画风放去 `-1.09`、人物放去 `0.35`；<br>3. 检查确认练的时候没把 `Alpha` 设太小。 |
| **刚启动特征提取就提示爆显存 / OOM** | 检查【文本提取设备】是不是误改成了 `cuda`（8G/12G 请锁定 `cpu`）；或者【显存档位】没有设为 `auto` / 对应小档位；1024 跑长文本报错可把【训练分辨率】切为 `896` 或 `768`。 |
| **人物左右胸章、独眼眼罩在生图时老左右乱跑** | 你在折叠抽屉里不小心勾选了【镜像翻转 Flip】！人物角色务必保持 `Flip` 不勾选。 |
| **练出来在 ComfyUI 里画风模糊、颜色发黑发焦** | 90% 的情况**并不是 LoRA 没练好**，而是 ComfyUI 生图工作流没对准 MOSS-Image 的流匹配规则！请立刻按下面第六节核对工作流。 |

## 六、ComfyUI 生图避坑铁律（练好了别在最后一步画废了）

MOSS-Image 和传统 SDXL / Flux 推理参数很不一样，测试你的 LoRA 时请把工作流严格设为：

1. **采样步数 Steps**：**至少 `50` 步**（用 `MOSS-Image-Base` 甚至需要 `>= 50` 步；步数只有 20 步画面必然模糊糊掉）。
2. **Shift（采样偏移）**：生图节点（ModelSamplingFlux / AuraFlow 等）里设 **`Shift = 5.0`**！（**记住口诀：训练锁 1.0，生图调 5.0**，千万别反了）。
3. **CFG 引导系数**：设在 **`3.0 ~ 3.5`**！绝对不要沿用习惯填 `7.0` 以上，否则画面会立刻烤焦发黑。
4. **负面提示词 (Negative Prompt)**：**留空**！一个词都别填。
5. **SLG（Skip Layer Guidance）**：如支持 SLG 节点，设置跳过 **第 `22` 层** 能显著消灭散焦糊化问题。
6. **LoRA 权重强度**：先从 **`0.6 ~ 0.8`** 试起，并用自然语言长句触发效果最佳。
